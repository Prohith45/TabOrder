# TabOrder Project Rules

## Progress Tracking
- **Always update `progress.md`** after every change, edit, or step execution.
- Log what was done, which files were added/modified, and any validation results.
- Append new entries chronologically — never overwrite previous entries.

## Development Rules
- Build strictly in isolated phases (Steps 1–6).
- Maintain clean relational database integrity.
- No bloated libraries.
- Frontend communicates exclusively through the REST API — no direct DB access.
